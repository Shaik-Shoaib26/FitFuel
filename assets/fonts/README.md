# Bundled FitFuel typefaces

These are the existing FitFuel typefaces, now bundled to remove runtime font fetching. No new package dependency was introduced, and pubspec.lock was unchanged.

Downloaded from the official Google Fonts repository on 2026-09-12:

- [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans): upright and italic variable fonts; license in PlusJakartaSans-OFL.txt.
- [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit): upright variable font; license in Outfit-OFL.txt.

The original SIL Open Font License files are included in the application asset bundle. Font files are unmodified. Typography sets explicit weight variations for predictable variable-font rendering.
